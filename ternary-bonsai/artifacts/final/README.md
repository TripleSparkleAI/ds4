# `final/` - the versions we would stand behind

> ⛔ **EMPTY, AND IT WILL STAY EMPTY FOR A WHILE.** Nothing has been quantised, so nothing can be
> final. And a file only moves here after `../../methods/03-P1-the-quality-measurement.md` has
> passed on it **with its expert-selection agreement number**, not on NLL alone.

## What makes something final

    [ ] it passed P1's gate, including EXPERT-SELECTION AGREEMENT per layer, not pooled
    [ ] its NULL arm was clean, so the result is attributable to ternary and not to the plumbing
    [ ] its INDEX row is complete: bytes, sha256, source checkpoint, imatrix, commit, box, date
    [ ] its method is reproducible from what is written down, by somebody who was not there

## ⚠ FINAL IS PLURAL

The method has variants - layer subsets, imatrix corpora, bit widths - so **there will be several
finals worth standing behind**, and they must not be confusable. The naming scheme across the set
and the publication plan for all of them: `../../HF_PUBLICATION_PLAN.md`.

## ⛔ Nothing here is published

A file landing in this directory is **not** a decision to host it. The licence question alone is
open and is the navigator's, not a lane's. `../../HF_PUBLICATION_PLAN.md`.
