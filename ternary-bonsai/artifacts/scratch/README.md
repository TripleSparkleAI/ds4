# `scratch/` - runs that failed or were superseded

> ⚠ **EMPTY. Nothing has been run.**

## ★ KEPT, NOT DELETED

A superseded run is the evidence for why the current one is shaped the way it is. This estate's
storage law sorts artifacts into **RE-DOWNLOADABLE** (a tested, dated fetch path exists - the only
class safe to delete), **DERIVED** (re-obtainable by redoing work; record the hours) and
**IRREPLACEABLE** (moved only, never removed). ⇒ **a failed run's output is usually DERIVED, and
DERIVED is not disposable** - it cost hours.

## ⚠ But it is not a landfill either

    [ ] every file here still gets an INDEX row, with WHY it was superseded
    [ ] a file with no row and no explanation is the thing this directory exists to prevent
    [ ] when the disk needs the space: delete RE-DOWNLOADABLE first, and leave a STONE

★ **The INDEX row for a scratch artifact is more useful than the artifact.** "This arm was
superseded because its imatrix was calibrated under the wrong rotation state" is the finding; the
bytes are just the bytes.
